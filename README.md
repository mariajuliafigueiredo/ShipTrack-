# ShipTrack

Shipment management and tracking web application designed to centralize shipment information and provide visibility into delivery progress.

- **Project type:** Full Stack Web Application
- **Domain:** Transportation & Logistics
- **Status:** Planning

## Overview

ShipTrack explores how software solutions can support logistics operations, improve information management and simplify shipment tracking. Users can register shipments, update statuses, consult tracking history, monitor delays and incidents, and view operational indicators on a dashboard.

## Tech Stack

- **Backend:** C# / ASP.NET Core Web API
- **Frontend:** React / TypeScript
- **Database:** SQL Server
- **API documentation:** Swagger / OpenAPI
