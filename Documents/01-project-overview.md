# ShipTrack — Project Overview

**Project type:** Full Stack Web Application
**Domain:** Transportation & Logistics
**Status:** Planning

## 1. Project Description

ShipTrack is a shipment management and tracking web application designed to centralize shipment information and provide visibility into delivery progress.

## 2. Problem Statement

Shipment management involves different stages, status updates and operational events. When information is scattered or difficult to access, it becomes hard to track deliveries and identify potential delays.

ShipTrack addresses this problem by providing a centralized platform where users can manage shipments, consult their tracking history and monitor delayed or problematic deliveries.

## 3. Project Objectives

- Centralize shipment information.
- Provide visibility into shipment status.
- Maintain a history of shipment events.
- Identify delayed or problematic shipments.
- Present relevant operational information through a dashboard.

## 4. Target Users

**Operations Staff**
Responsible for registering shipments, updating statuses, recording incidents and monitoring delivery progress.

**Administrators**
Responsible for managing system information, user access and monitoring overall operations.

**Customers (future phase)**
Not part of the MVP. In a later phase, customers could consult shipment information and delivery progress.

## 5. Proposed Core Features

- Shipment registration and management.
- Customer information management.
- Shipment status updates.
- Tracking history.
- Delay and incident tracking.
- Search and filtering.
- Dashboard with operational indicators.
- User authentication and role-based access (Operations Staff and Administrators).

## 6. Initial Project Scope

The first version (MVP) will focus on shipment management, tracking history, incident tracking and operational visibility.

Advanced features such as external carrier integrations, automated notifications, customer access and real-time GPS tracking are outside the initial scope.

## 7. Expected Outcome

A functional web application demonstrating how software development, database management and logistics processes can be combined to create a practical digital solution that supports logistics operations and simplifies shipment tracking.

## 8. Proposed Technologies

- **Backend:** C# / ASP.NET Core Web API
- **Frontend:** React / TypeScript
- **Database:** SQL Server
- **API documentation:** Swagger / OpenAPI
- **Version control:** Git / GitHub
